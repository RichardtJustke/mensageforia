Mensageforia is a personal automation project built with Go (Fiber). Hosted on a local home server using Docker, it integrates with a local LLM via Ollama to generate random motivational messages. Every day at 1:00 AM, a random number (1–10) determines how many messages will be generated that day, distributed evenly across a configurable window (default 08:00–20:00). Each message is saved to SQLite and to a markdown file, then automatically committed and pushed to the repository.
